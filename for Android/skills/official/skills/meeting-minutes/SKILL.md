# 会议纪要

1. 拿到原文：
   - 录音或视频文件：先用 transcribe_audio 转成文字；
   - 文档：read_document；文字直接用。
   原文很长时分段读完再写，不要只看开头。
2. 纪要结构：
   ```
   # 会议纪要：主题
   时间 / 地点 / 参会人（原文里有才写）
   ## 讨论要点（按议题，每题 2～4 条）
   ## 决议
   ## 待办事项
   | 事项 | 负责人 | 截止时间 |
   ## 待定问题
   ```
3. 规则：
   - 决议和待办只写原文里明确说了的；负责人、时间没说的写「未明确」；
   - 口语整理成书面语，去掉重复和寒暄，但不改变意思；
   - 不同人观点不一致的地方如实写分歧。
4. 输出：回复里给纪要全文；用户要文件时用 create_docx 存到工作区 `meetings/日期-主题.docx`。
5. 待办里有明确日期时，问用户要不要加到日历提醒（同意后用 add_calendar_event）。
