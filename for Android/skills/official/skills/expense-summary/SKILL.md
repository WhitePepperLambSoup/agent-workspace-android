# 记账与消费汇总

1. 读账单：
   - 截图、照片：识别图里的文字（屏幕或图片 OCR），看不清的金额标出来请用户确认；
   - 表格、导出的账单（xlsx / csv / pdf）：read_document；
   - 文字：直接用。
2. 每笔记录：日期、金额、商户或用途、支付方式、类别。类别默认：餐饮、交通、购物、日用、居住（房租水电）、通讯、娱乐、医疗、学习、人情往来、其他；用户有自己的分类就用用户的。
3. 去重：同一笔在截图里重复出现、退款与原支付对冲时说明处理方式；收入和转账不算消费（单独列出）。
4. 汇总：
   - 总支出、日均；
   - 各类别金额和占比，从高到低；
   - 最大的 5 笔；
   - 有上期数据时比较变化。
5. 输出：结论在回复里；明细和汇总用 create_xlsx 存到工作区 `expenses/年-月.xlsx`（第一张汇总、第二张明细，合计用公式）。工作区里已有当月文件时追加，不要覆盖。
6. 用户问要不要省钱建议时，再根据数据给 2～3 条具体建议。

不要把账单内容发到任何外部服务。
