# 润色与翻译

1. 先判断要做什么：润色 / 改写（换说法）/ 缩写到 N 字 / 扩写 / 翻译（目标语言）。不清楚时按文字和用户的话推断；仍不清楚再问。
2. 风格：按用途调整——学术（准确、客观、术语统一）、商务（礼貌、简洁）、文案（有感染力）、口语。用户指定了就按指定的来。
3. 规则：
   - 不改变原意，不添加原文没有的事实；
   - 专有名词、产品名、代码、公式、数字和单位保持不变；
   - 翻译时术语前后一致；中文译文用中文标点，避免翻译腔；
   - 原文有明显错误（事实、错别字）时改正并说明。
4. 输出：
   - 先给结果全文；
   - 改动较多时，再列 3～5 条主要修改说明（例如「把被动句改为主动」「统一了术语 X」）；
   - 用户要对照时，用「原文 / 修改后」两列表格逐句对照。
5. 长文档（附件）：read_document 读入，分节处理；结果用户要文件时按原格式用 create_docx 输出。
