# 行程规划

1. 先确认关键信息（缺的问一次，一起问）：出发地和目的地、日期和天数、人数（有无老人小孩）、预算、偏好（自然 / 人文 / 美食 / 购物、节奏松紧）、交通方式。
2. 查资料：用联网搜索（web_search 或 browser）查景点开放时间、是否需要预约、门票、当地交通、天气。查不到的信息写「出发前确认」，不要编。
3. 排行程：
   - 按天排，每天上午 / 下午 / 晚上，同一天的地点尽量在同一片区域；
   - 写清景点之间怎么走、大约多久；
   - 留出吃饭和休息时间，第一天和最后一天考虑到达、返程；
   - 给 1～2 个雨天或体力不够时的备选。
4. 预算：交通、住宿、门票、餐饮分项估算，注明是估计。
5. 输出：Markdown 行程表；用户要文件时用 create_docx 或 create_pdf 存到工作区 `travel/`。
6. 问用户要不要把每天的关键安排（出发、需要预约的时间）加进日历或设闹钟：同意后用 add_calendar_event / set_alarm。

不替用户订票、付款或填写身份信息。
