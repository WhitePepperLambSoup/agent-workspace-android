# 菜单与采购清单

1. 问清（缺的一次问完）：几天、几顿、几个人、口味和忌口、过敏、特殊需要（减脂、控糖、低盐、孩子、老人）、做饭时间和厨具、预算。
2. 排菜单：
   - 每天荤素搭配，有主食、蛋白质和蔬菜；
   - 同一种食材在几天里用完，减少剩余；
   - 工作日选 30 分钟内能做好的，周末可以稍复杂；
   - 特殊需要按常识处理（控糖少精米面和甜饮、低盐少腌制品），不给医疗承诺；有疾病的提醒遵医嘱。
3. 每道菜写：主要食材和大致用量、做法要点（3～5 步）、预计时间。
4. 采购清单：合并所有菜的食材，按区域分组（蔬菜水果、肉蛋水产、豆制品、主食、调料干货），写总量；家里常备的调料单列「确认家里有没有」。
5. 输出：Markdown 菜单表（天 × 顿）和采购清单；用户要文件时用 create_docx 或 create_xlsx 存到工作区 `meals/`。
6. 用户要提醒时，问清时间再用 add_calendar_event 或 set_alarm（例如解冻、去菜市场）。

不替用户在买菜 App 里下单或付款；用户要比价时只查看，不提交订单。
