# 手机体检

只读取，不改任何设置、不删任何东西。

1. 电池：`android_battery` 读电量、充电状态、温度。
2. 耗电：`android_action` open_page battery，读「耗电排行 / 应用耗电」前 5 名（没有这一项就跳过；有「电池健康 / 最大容量」也记下）。
3. 存储：open_page storage，读总容量、已用、各分类（应用、图片、视频、其他）。
4. 应用：open_page apps，读应用数量；按「最近安装 / 按安装时间」排序时记下最近 5 个。
5. 温度高于 40°C、电量低于 20% 不在充电、可用空间少于 10% 时，标为「需要注意」。

## 报告格式

```
【手机体检】
电池：xx%，充电中/未充电，温度 xx°C（电池健康：xx 或 未显示）
耗电最多：A xx%、B xx%、C xx%
存储：已用 xx / 共 xx（剩余 xx%）；占用最多：图片 xx、应用 xx …
最近安装：…
需要注意：…（没有就写「无」）
建议：1～3 条具体建议（例如清理哪类文件、关闭哪个应用的后台）
```

页面上读不到的项写「未显示」，不要猜。最后按 home 回到桌面。
