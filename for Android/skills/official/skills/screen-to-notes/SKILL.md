# 屏幕转笔记 / 日程

1. 读屏幕：`android_observe` 带 screen_text（图片里的字也会识别）；内容是长文章时向下 scroll 继续读，直到读完或用户说的范围结束。图片、海报读不清时用 `android_screenshot`。
2. 整理成 Markdown 笔记：
   - 标题（来源 App + 主题）；
   - 要点（3～8 条）；
   - 原文中的关键数据、链接、联系方式照抄，不改；
   - 末尾注明来源和整理时间。
3. 保存：
   - 默认用 write_file 存到工作区 `notes/日期-主题.md`；
   - 用户说「存到知识库」时用 knowledge_add 把这个文件加入知识库。
4. 内容里有明确的时间（和地点）的活动、会议、截止日期时：列出来问用户要不要加到日历；用户同意后用 add_calendar_event 逐个添加（标题、开始时间、地点、备注写来源）。时间不完整（只有日期没有钟点）时先问。
5. 回复：笔记保存位置 + 要点摘要 +（如果有）已加入日历的事件。

聊天截图里的他人隐私（电话、地址、身份证号）不要写进笔记，除非用户明确要求。
