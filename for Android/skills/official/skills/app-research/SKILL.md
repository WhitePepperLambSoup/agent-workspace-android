# 内容搜索汇总

1. 确定话题和用户关心的点（例如「XX 耳机 降噪 和 续航」）。
2. 选 App：用户指定的优先；没指定时按话题选——生活攻略和好物用小红书，问答和经验用知乎，测评和教程视频用 B站。
3. 在 App 里搜索：launch_app → 点搜索框 → type_text 关键词 → enter。读结果列表，挑前 5 条相关度高、互动多（赞、收藏、评论多）的内容，逐条点进去读要点，读完 back。视频只看标题、简介和高赞评论。
4. 这个 App 要求登录才能看搜索结果或正文时：换下一个 App；都不行就用联网搜索（web_search 或 browser）在网页上找同类内容，并告诉用户是从网页找的。
5. 记下每条的来源（App + 标题/作者）和要点，不要编造没看到的内容。

## 回复格式

```
【话题】xxx（看了 N 条：小红书 x 条、知乎 x 条…）
主要观点：
- …（来源）
共识：…
分歧 / 争议：…
值得注意：（广告嫌疑、过时信息等）
```

只读：不点赞、不评论、不关注、不私信。
