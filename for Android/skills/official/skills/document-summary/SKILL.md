# 长文档与合同要点

1. 读全文：read_document（扫描件会自动识别文字），文档长时按 next_page 继续读完，不要只读前几页。
2. 先给一段 3～5 句的总体概述（这是什么文件、主要讲什么、和用户有什么关系）。
3. 按文档类型：
   - 报告 / 论文：研究问题、方法、主要结论和数据、局限；
   - 说明书 / 政策：适用对象、要做的步骤、期限、注意事项；
   - 合同、协议：
     - 双方、标的、金额、付款方式和时间；
     - 期限、续约、提前解约的条件和违约金；
     - 押金、保证金怎么退；
     - 责任和赔偿、免责条款；
     - 自动续费、单方变更、争议解决（仲裁 / 法院、地点）；
     - 对用户不利或模糊的条款单独列出，引用原文和页码。
4. 引用原文时注明页码；文件里没有的内容不要推测。
5. 结尾提醒：这是阅读辅助，重要合同请咨询专业人士。
6. 用户要文件时把要点用 create_docx 存到工作区。
