# AA 分账

1. 收集账目（从文字、账单截图或表格）：每笔的金额、谁付的、哪些人参与。看不清或缺的问一次。
2. 确认分法（没说就按平均分）：
   - 平均分；
   - 按份（某人只吃了一部分、小孩算半份）；
   - 按实际消费（各点各的，公共部分平摊）；
   - 有人不参与某一笔（只算参与的人）；
   - 优惠、服务费、红包抵扣：按金额比例分摊到参与的人。
3. 计算：每人应付、每人已付、差额 = 已付 − 应付（正数是多付、应收，负数是少付、应给）。所有人的差额加起来必须是 0，不是 0 就是算错了，重算。金额用两位小数，最后一分钱的误差说明给了谁。
4. 结算方案：只有差额为负的人转出，只有差额为正的人收款；多付的人绝不转出。把应给最多的人配给应收最多的人，依次配对，用最少的转账次数两清，写成「张三 → 李四 12.50 元」。
   写出之前逐人核对：每个人「已付 + 转出 − 收到」都等于他的应付；每个人收到的总额等于他的正差额，转出的总额等于他的负差额。有一项对不上就重新配对。
5. 输出：
   - 先给转账清单；
   - 再给明细表（每笔、每人应付）；
   - 用户要文件时用 create_xlsx 存到工作区 `bills/`，公式算合计，方便以后核对。
6. 用户说「发到群里」时，只把转账清单整理成一段可复制的文字，由用户自己发送。

不替任何人转账、不打开支付 App 付款。
