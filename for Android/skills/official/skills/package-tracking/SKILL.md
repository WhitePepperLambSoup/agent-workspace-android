# 快递查询

1. 先看通知栏和短信里有没有取件码：`android_action` notifications 读一遍，记下取件码和位置，再 back 收起。
2. 依次查用户用的购物 App（没说就查已安装的：菜鸟、淘宝、京东、拼多多）：
   - 菜鸟：首页的包裹列表（「我的包裹」）。
   - 淘宝：「我的淘宝 → 待收货」。
   - 京东：「我的 → 待收货」。
   - 拼多多：「个人中心 → 待收货」。
   用 `tap_text` 点这些字；找不到就 `scroll_to_text`。
3. 每个包裹读：商品名（简短）、快递公司、最新物流状态和时间、预计送达。需要时点进单个订单看物流详情，看完 back。
4. 遇到登录页：停下，记为「X 需要先登录」，不要输入账号；没安装的记为「未安装」。
5. 同一个包裹在几个 App 里重复出现时只列一次。

## 回复格式

```
【快递】共 N 个在途
1. 商品 · 快递公司 · 最新状态（时间）· 预计送达
…
待取件：取件码 xxxx（驿站/快递柜位置）
未能查看：淘宝（需要登录）…
```

只读不改：不确认收货、不申请退款、不催单，除非用户明确要求并确认。
