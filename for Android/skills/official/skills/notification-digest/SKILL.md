# 通知整理

1. `android_action` notifications 拉下通知栏，然后 `android_observe`（读不清时 `android_screenshot`）。通知多时用 scroll 往下翻，直到没有新内容。
2. 每条通知记下：来自哪个应用、标题、正文要点、时间。
3. 分类：
   - 验证码：列出应用和验证码（只给用户看，不要拿去填写任何地方）；
   - 快递取件：快递公司、取件码、驿站或柜子位置；
   - 工作 / 日程：会议、待办、审批；
   - 聊天消息：谁发来的、要点（不展开隐私细节，只说有几条、来自谁）；
   - 系统与其他；
   - 广告推广。
4. 回复先给一句话总结（共几条、最要紧的是什么），再按类列出；没有的类别不写。
5. 用户要求清理某类时：先列出要清的通知让用户确认，确认后逐条左右滑动清除（或点该应用通知上的「清除」），不要点「全部清除」，除非用户明确要全部清掉。
6. 结束时按 back 收起通知栏。

不要点开通知（会把消息标为已读），除非用户要求打开某一条。
