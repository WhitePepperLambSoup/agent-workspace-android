# 每日签到

目标：依次进入用户指定的 App，完成签到或领取每日奖励，最后汇总结果。用户没指定 App 时，先问要签哪些（可以记到记忆里，下次直接用）。

## 每个 App 的做法

1. `android_action` launch_app（app_name 用 App 的中文名）。没有安装就记为「未安装」，跳过。
2. 先处理挡在前面的东西：结果里的 blocking 指出的开屏广告点「跳过」，更新提示点「以后再说 / 取消」，「同意隐私政策」这类首次启动的协议按用户要求处理（用户让你签到即视为同意继续使用该 App）。
3. 找入口，按顺序试 `tap_text`，找到一个就停：
   「签到」「每日签到」「去签到」「立即签到」「领京豆」「领金币」「签到领」。
   首页没有时，切到「我的」页再找；仍然没有就 `scroll_to_text` 往下找「签到」。
   常见位置：京东「我的 → 京豆 → 签到领京豆」；淘宝「我的淘宝 → 淘金币」；美团「我的 → 签到」；拼多多「个人中心 → 签到」；网易云音乐「我的（左上角菜单）→ 签到」。
4. 点了之后看结果：出现「已签到」「签到成功」「+N」「明天再来」即为成功；记下得到的东西。签到后常弹出「看视频再领」「去逛逛」「翻倍领取」之类的广告，点它的关闭（×），不要点进去；整个过程中任何时候弹出广告都先关掉再继续，不小心进了广告页就返回。
5. 出现登录页（手机号、验证码、密码、「登录后」）：**停在这里**，记为「需要先登录」，不要输入任何账号信息。
6. 出现滑块、拼图、点选文字等人机验证：停下，记为「需要你手动验证」，不要尝试绕过。
7. 按 home 回到桌面，再做下一个 App。

## 汇总

最后用列表回复，每个 App 一行：成功（得到什么）/ 已签过 / 需要登录 / 需要手动验证 / 未安装 / 没找到入口。
第一次在某个 App 成功后，把入口路径用一句话写进记忆（memory_write），下次直接走。

## 不要做

不付款、不开通会员、不点「领取后自动续费」类按钮；不替用户填写手机号或验证码。
