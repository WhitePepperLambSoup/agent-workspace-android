# 简历修改

1. 读材料：简历附件用 read_document；岗位描述（JD）用户给了就一起读，链接用 web_fetch 打开。没有简历时按问答收集：教育、工作或实习、项目、技能、证书。
2. 先给整体意见（3～5 条）：岗位匹配度、最大的缺点、最该补的内容。
3. 逐段修改：
   - 经历写成「做了什么 + 怎么做 + 结果」，结果尽量量化（用户没给数字时用「约 __%」占位并提醒补上，不编造）；
   - 动词开头，删掉空话（「负责相关工作」「认真负责」）；
   - 按 JD 的关键词调整顺序和用词，相关的放前面；
   - 应届生突出项目、实习和技能，社招突出近三年的成果；
   - 一页为宜，最多两页；时间倒序，格式统一。
4. 检查：错别字、时间是否连续、联系方式是否完整、不同经历里的同一件事是否矛盾。
5. 输出：修改后的全文；改动多时附「原文 / 修改后」对照。用户要文件时用 create_docx 存到工作区 `resume/`（保留用户原文件不覆盖）。
6. 求职信或自我介绍：按岗位写 200～300 字，开头说明应聘什么，中间两三点匹配理由，结尾表达意愿。

不编造经历、学历、证书或数据；不把简历发给任何人或网站，投递由用户自己完成。
