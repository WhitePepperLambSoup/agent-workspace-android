name: scam-check
description: 用户转来一条短信、聊天消息、链接、来电说辞、二维码或截图，问「这是不是诈骗」「能不能点」「要不要转账」时使用。

# 识别诈骗信息

1. 拿到要判断的内容：
   - 文字：直接用；
   - 截图：识别图里的文字，注意发件号码、链接和二维码旁的说明；
   - 只说了「刚才那条短信」：征得同意后看通知或短信，只看这一条。
2. 只看不碰：不打开链接、不扫码、不回拨电话、不回复、不下载附件。要查链接时只分析网址文字，不访问它。
3. 对照常见手法逐条检查，命中的写出来：
   - 冒充：公检法、客服、快递、银行、领导、熟人、学校老师；
   - 要钱：转账到「安全账户」、刷流水、交保证金 / 解冻费 / 手续费、先垫付再返还；
   - 要信息：验证码、银行卡号、身份证、密码、屏幕共享、下载会议或「远程协助」类 App；
   - 制造紧迫：限时、账户冻结、涉嫌犯罪、包裹违规、征信受影响、退款理赔；
   - 链接和号码：短链接、拼写相近的仿冒域名、非官方号码发来的「官方通知」、个人号码冒充 95 开头客服；
   - 高回报：刷单返利、投资带单、兼职点赞、低价卖游戏装备或演唱会门票。
4. 需要时用 web_search 查这种说法或号码是否被报道过（只搜文字，不访问可疑链接）。
5. 结论三选一，放在第一行：
   - **很可能是诈骗**；
   - **需要核实**（说清楚该向谁、通过什么官方渠道核实）；
   - **看起来正常**（也提醒仍不要把验证码给任何人）。
6. 然后：命中的疑点（2～5 条，引用原文）、现在该做什么（不点、不转、拉黑、删除）、已经转账或泄露信息时的补救（立即打银行客服冻结、报警 110、拨打反诈专线 96110、修改密码）。

用简单直接的话写，用户可能是老人。不要替用户回复对方、不要拨打任何号码、不要转账。
