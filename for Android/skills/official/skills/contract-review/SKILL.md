# 合同要点与风险

1. 读全文：附件用 read_document；截图识别文字；太长时分节读，不要只看开头。看不清的条款标出来请用户补全。
2. 先问清（缺的一次问完）：用户是哪一方、最在意什么（钱、期限、能不能提前走、押金）、有没有已经谈好但合同里没写的事。
3. 列要点表：双方、标的、金额和付款方式、期限和续期、交付或验收、押金和退还、违约责任、提前解除、争议解决（仲裁还是法院、在哪）。合同没写的项写「未约定」。
4. 找风险，逐条引用原文并说明为什么不利：
   - 只约束一方的违约金或解除权；
   - 押金、定金、预付款不退或扣除条件模糊；
   - 自动续期、默认同意、单方变更条款或价格；
   - 过高的违约金、无限连带责任、放弃法定权利（如劳动合同里放弃社保、加班费）；
   - 管辖地在对方所在地、只能仲裁；
   - 口头承诺没有写进合同；
   - 金额、日期、名称前后不一致，空白处未填。
5. 给修改建议：每个风险对应一句可以直接发给对方的修改措辞。
6. 输出：结论（可以签 / 改了再签 / 不建议签）放第一行，然后要点表、风险和建议。用户要文件时用 create_docx 存到工作区 `contracts/`。

注明这是阅读辅助，不是法律意见；金额大或有纠纷时建议咨询律师。不替用户签名、不填写身份证号或银行卡号。
