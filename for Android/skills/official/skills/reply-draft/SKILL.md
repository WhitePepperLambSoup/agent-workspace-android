# 回复草稿

**只填进输入框，绝不点「发送」。** 发送永远由用户自己点。

1. 确认聊天窗口：当前屏幕应是一个聊天界面（顶部有对方名字、底部有输入框）。不在聊天界面时，问用户要回谁；用户给了名字就打开对应 App，在会话列表里 tap_text 对方名字进入。遇到登录页就停下，告诉用户需要先登录。
2. 读上下文：`android_observe` 读最近的消息；需要时往上 scroll 一两屏，弄清对方在问什么、语气如何。
3. 写回复：
   - 符合用户的要求（同意 / 婉拒 / 改约时间 / 道谢…）和双方的语气（对长辈、同事、朋友不同）；
   - 简短自然，像本人说的话，不用书面语和表情包堆砌；
   - 用户没说态度又不好判断时，先给 2 个不同方向的草稿让用户选。
4. 点输入框，type_text 把选定的草稿填进去（只填一个）。
5. 告诉用户：「已填在输入框里，确认没问题就自己点发送」，并把草稿原文也写在回复里。

不要转发、不要撤回、不要读或回复用户没提到的其他聊天。
