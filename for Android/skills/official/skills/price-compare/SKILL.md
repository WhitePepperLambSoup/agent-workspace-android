# 比价

1. 明确要比的商品：品牌、型号、规格（容量、颜色、件数）。用户说得不清楚时先问一句，避免比错东西。
2. 依次在 2～3 个 App 里搜索（用户没指定就用已安装的京东、淘宝、拼多多）：
   - launch_app，点顶部搜索框（tap_text「搜索」或搜索框里的提示字），type_text 输入商品名，再 enter；
   - 看前几条结果，找规格完全一致的；优先官方旗舰店 / 自营；带「广告」「推广」「赞助」角标的结果不算，跳过看下一条；
   - 搜索途中弹出的红包、优惠券、活动弹窗点它的关闭（×），不要点「领取」「去看看」；
   - 记下：价格（到手价，有「券后」「到手」写明）、店铺、销量或评价数、明显的优惠（满减、百亿补贴、包邮）。
3. 搜索要求先登录时：跳过这个 App，记为「需要登录才能搜索」。
4. 不要点「立即购买」「加入购物车」「领券」，不要进入下单或支付页面。

## 回复格式

```
【比价】商品：xxx（规格）
京东：¥xxx · 店铺 · 优惠 …
淘宝：¥xxx · 店铺 · 优惠 …
拼多多：¥xxx · 店铺 · 优惠 …
最便宜：xx（便宜 ¥xx）；更推荐：xx（理由：自营 / 官方店 / 售后）
未能查看：…
```

价格会随时间和账号变化，提醒用户下单前再看一眼。
