          已保存的模型配置
          
在常用的服务商和模型之间一键切换。云端模型之间切换不用重启引擎；切换到或离开本机模型时会重启。API 密钥按服务商地址保存在系统密钥库，配置里不含密钥。

          

          

          

        

        
        

        
        
临近容量时由当前模型总结较早记录。会额外调用模型，可能产生 Token 费用；摘要可能遗漏细节，原始会话仍保留。

          添加规则
          
          
          
          
          
任务在当前会话里运行，使用当前的模型。执行权限和平时一样，需要批准的操作仍会先问你。每条规则至少间隔 30 秒，每天最多运行 30 次。

          

        

        
最近触发

      

      

        
在手机的任何地方都能快速开一个新对话。

        
        
在其他应用上方显示一个小圆球：点一下开新对话；长按可以截屏提问、语音提问或隐藏它；拖动可以移到屏幕两侧。需要允许“显示在其他应用上层”，截屏提问还需要在“设备与工具”里开启无障碍服务。

        
        
也可以下拉通知栏，进入快捷开关的编辑页面，把“问 Agent”拖进去。

        
长按桌面上的 Agent Workspace 图标，可以直接选“新对话”“语音提问”或“拍照提问”。

        

      

      

        
AI 可以启动需要一直运行的程序，比如本地网页服务或机器人。任务结束后它们继续运行，直到你在这里停止，或者引擎停止。勾选“随引擎启动”的服务会在引擎重启后自动重新运行。

        
        
有服务运行时让手机在息屏后不休眠，更耗电。不开启时，息屏一段时间后服务会暂停，亮屏后继续。

        

        

      

      

        
        
        

        

          
          
          

        

        

        

        

      

      

        
把说明书、合同、笔记、电子书等文档加进来，聊天时 AI 会从中找相关段落回答，并注明出自哪份文档、第几页。文档只保存在这台手机上，按关键词检索，不用下载模型，也不消耗额度。

        
        
        
开启后，每次提问会先在知识库里找，找到相关段落就随问题一起发给模型；关闭后只在 AI 主动搜索时使用。

          内置浏览器
          
AI 用它打开网页、点按钮、填表和截图。打开网页和点击需要你批准，只读取当前页面不用。它的登录状态与应用界面分开保存。

          

          

        

        

          闹钟与日历
          
说“明早 7 点叫我”或“20 分钟后提醒我”，AI 会在系统时钟里设好闹钟或计时，不需要授权。查看和添加日程需要允许访问日历；在「工作区」执行模式下，添加日程前会先请你确认。

          
        

        

          可选开发工具链

          
安装 Git、Python、Node 和 Python 语言服务。下载约 70 MB，安装后需重启引擎。

          

          
        

        

          后台运行

          
系统仍可能暂停后台进程。中断的操作需要检查状态后恢复。

          
          
        

      

      

        

          版本与更新
          

          
          
          
关闭后不会在后台检查，仍可随时手动检查。从 GitHub 发布页下载，安装前会校验 SHA-256 和签名；安装需要你在系统安装界面确认。

        

        

          诊断日志
          
引擎出错、卡住或连不上时，把日志发给开发者排查。访问令牌和 API 密钥会自动隐藏；日志里可能有任务内容片段，请只发给信任的人。
