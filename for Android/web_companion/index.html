          已保存的模型配置
          
    在常用的服务商和模型之间一键切换。云端模型之间切换不用重启引擎；切换到或离开本机模型时会重启。API 密钥按服务商地址保存在系统密钥库，配置里不含密钥。
    
          
    
          
    
          
    
        
    
        
        
    
        
    
        
    
        
        
    临近容量时由当前模型（或下面设的摘要模型）总结较早记录。会额外调用模型，可能产生 Token 费用；摘要可能遗漏细节，原始会话仍保留。
    
        
    
          按用途分配模型
          
    手机操控、摘要压缩和子任务可以用同一服务商下更便宜的模型，普通对话仍用上面的主模型。留空就跟主模型一样；在对话或操控小窗里临时选的模型优先。使用本机模型时不适用。
    
          
          
          
          
    
          
    
        
    
        
    
          单个任务上限
          
    一个任务（连同它分出的子任务）花到上限就停下，并说明是哪项到了。费用按「Token 与费用」页的单价计算，没有单价的模型只按 Token 计。留空或填 0 表示不限。
    
          
          
          
    
          
    
        
    
        
    
          网关与备用 Key
          
    走网关或代理需要额外请求头时填在这里；同一服务商有多个 Key 时，一个被限流或失效会自动换下一个。都按当前服务商地址加密保存在手机里，保存后不再显示内容，重启引擎后生效。
    
          
    
          
          
          
          
          
    
          
    
        
    
      
    
      
    
        
    附件收件箱
    
        
    
        
    
        
    
        
    
        
    
      
    
      
    
        
    
        
    
          个人信息和断网
          
    用云端模型时才会用到。本机模型回答的消息不出手机；需要先在「本机模型」里下载一个。
    
          
          
          
          
        
    
        
    
          不再询问就发送的服务商
          
    发给这些服务商时不再每个对话询问。取消后，下次发送会先问你。
    
          
    
        
    
      
    
      
    
        
    开启后，AI 当队长：把问题拆给几位专家同时研究，需要时再请一位专家审阅，最后汇总回答并写明分歧。比普通对话多花几倍的时间和费用，适合需要多方面判断的问题。手机上的专家只查资料、读文件和网页，不改文件、不运行命令。需要云端模型。
    
        
        
    
        
        
        
    
        
    
          
    
          
          
    
        
    
        
        
    答案数字多、结论有分歧或事关重大决定时，队长先写成稿，请一位专家逐个复算、挑错，再给你最终答案。关掉会更快、更省。
    
        
        
        
    共用时，每位专家查这个对话选用的知识库。单独指定后，那位专家只查你给他的知识库，其他专家照旧。
    
        
    
          
    
          
          
          
    
        
    
        
    
          自定义专家
          
    写上名称和他负责什么、怎么做，固定成员里就能选他。
    
          
    
          
          
          
    
          
    
        
    
      
    
      
    
        
        
    
          
          
        
    
        
    液态玻璃让顶栏、输入区和菜单变成会折射光线的玻璃，内容从下方经过时会在边缘弯曲。在较旧的手机上更耗电。
    
        
    
          
          
    
            
            
            
            
            
            
            
            
            
          
    
          
    
            
            
          
    
          
          
    玻璃要在下方有颜色或内容时才看得出来。自定义壁纸只保存在这台手机上。
    
          
          
        
    
        
        
    
          
          
          
          
          
        
    
        
        
    切换语言后界面会重新载入；对话内容与模型回复不会被翻译。
    
        
        
        
        
        
        
        
    
          应用锁
          
          
          
          
    对话、记忆和 API 设置都存在这台手机上。开启后，重新打开应用或从后台回来时需要解锁；悬浮球、圈选提问这些快捷入口不受影响。
    
        
    
      
    
      
    
        
    备份包含全部会话、记忆、定时任务与流程、内置工作区的文件，以及模型和界面设置。不包含 API 密钥、已下载的本机模型和开发工具链；放在手机公共文件夹里的工作区本来就在你的文件中，也不会重复打包。
    
        
    
          备份口令（可选）
          
          
          
    设了口令，备份会加密成 .awbackup 文件，别人拿到也打不开；恢复时要输入同一个口令。口令不会保存在任何地方，忘了就无法恢复。
    
        
    
        
        
        
    
        
    恢复前的数据会在手机里保留一份，直到下次恢复时被替换。恢复后请到模型设置里重新填写 API 密钥。
    
      
    
      
    
        
    收到指定应用的通知时，让 AI 按你写的要求处理，比如“快递短信来了就记下取件码”。只读取你选定应用的通知，其他通知不会被读取；通知内容只交给这次触发的任务，不会另外保存。
    
        
        
        
    
        
    
        
    
          添加规则
          
          
          
          
          
    任务在当前会话里运行，使用当前的模型。执行权限和平时一样，需要批准的操作仍会先问你。每条规则至少间隔 30 秒，每天最多运行 30 次。
    
          
    
        
    
        
    最近触发
    
        
    
          通知摘要
          
    打开后，手机收到的通知会记在手机上（48 小时后自动删除；验证码不记录；不让 AI 碰的应用不记录），AI 可以把它们整理成“要处理、可稍后、广告”，并把取件码、航班车次、会议变更、账单这类信息单独列出来。整理时通知内容会交给当前模型，用手机上的本地模型就完全不出手机。
    
          
          
    
            
            
          
    
          
    
        
    
      
    
      
    
        
    长辈模式把整个界面换成一个大大的「说话」按钮：按一下说出想问的事，AI 用简短的话回答，并读出来。设提醒、问手机怎么用，也都直接说。另有「拍照问问」和「打给家人」两个按钮。适合家里的老人用，最好由家人先在这里设置好。
    
        
    
          家人
          
          
          
    电话只存在这台手机上，不会发给 AI。称呼会告诉 AI，遇到像是骗局的事时，它会提醒先问家人。
    
          
    设了电话后，长辈界面会有「求救」按钮：按下后写好一条给家人的短信，由长辈自己按发送。
    
          
        
    
        
        
        
    
          退出密码
          
    设了以后，退出长辈模式要输入这个数字密码，免得误操作退出。可以不设。
    
          
          
    
        
    
        
    
        
    进入后不再向长辈询问任何事：AI 直接回答、查询，也会直接替长辈操作手机。付款和转账任何时候都不会做；AI 读到的内容里像有人在指使它（常见于骗局）时，它会停下不做。银行、支付类应用建议加到「设备与工具 → 不让 AI 操作的应用」里。
    
        
      
    
      
    
        
        
    看看你自己装的应用拿了哪些大权限（读屏幕、读通知、设备管理器等），是不是从应用商店装的，有没有桌面图标，会不会自己弹出来。这不是病毒扫描，只看系统给出的事实，要不要处理由你决定。卸载时会弹出系统的确认框。
    
        
    
        
    
        
    其他应用
    
        
        
    大约每 30 分钟看一次：新装的应用拿到大权限，或已有的应用新拿到设备管理器、无障碍这类权限时，发一条通知，点开就是这一页。
    
        
        
    打开后，会记下哪个应用在你没点它时自己跳到前台，或用悬浮窗盖住大半个屏幕。只记应用和时间，保存 7 天，不离开这台手机；关闭时清除。需要开着本应用的无障碍服务。
    
        
    
        
      
    
      
    
        
    在手机的任何地方都能快速开一个新对话。
    
        
        
    在其他应用上方显示一个小圆球：点一下展开操作手机、新对话、语音提问、圈选提问（圈出屏幕上想问的部分）和录音速记；拖动可以移到屏幕两侧，拖到底部的 × 上就隐藏它。需要允许“显示在其他应用上层”。「操作手机」在当前应用上弹出小窗，直接告诉 AI 要做什么，它用无障碍服务替你点按、输入和滑动；系统设置等页面会隐藏悬浮球，可以先在别处呼出小窗，再让 AI 打开设置去做。圈选提问每次会请你允许截取屏幕；在“设备与工具”里开启无障碍服务后就不再询问。
    
        
        
    也可以下拉通知栏，进入快捷开关的编辑页面，把“问 Agent”拖进去。
    
        
    长按桌面上的 Agent Workspace 图标，可以直接选“新对话”“语音提问”或“拍照提问”。
    
        
    
          
          
          
        
    
        
    也可以长按桌面空白处，在“小组件”里找到 Agent Workspace。
    
        
    
          其他应用发起任务
          
          
    关闭时，每次有应用发起任务都会先弹窗让你确认，并显示来源和内容。发起的任务和平时一样，需要确认的操作仍会询问。
    
          
    用法：发送 Intent，动作 com.agentworkspace.mobile.action.RUN_TASK，目标 Activity com.agentworkspace.mobile/.entry.ExternalTaskActivity，附加文本 prompt（要做的事）；要操作手机再加布尔值 phone_control = true。
    
        
    
        
    
      
    
      
    
        
    AI 可以启动需要一直运行的程序，比如本地网页服务或机器人。任务结束后它们继续运行，直到你在这里停止，或者引擎停止。勾选“随引擎启动”的服务会在引擎重启后自动重新运行。
    
        
        
    有服务运行时让手机在息屏后不休眠，更耗电。不开启时，息屏一段时间后服务会暂停，亮屏后继续。
    
        
    
        
    
      
    
      
    
        
        
        
    
        
    
          
          
          
    
        
    
        
    
        
    
        
    
        
    
        
    
          应用经验
          
          
    AI 操作手机时，手机会记下在每个应用里点哪些按钮能打开页面、哪些点了没反应；AI 也可以记几句某个应用怎么用。之后的任务再进入这个应用时会先看到这些。只保存在这台手机上，不记录输入的文字和带长串数字的内容。
    
          
    
          
    
        
    
      
    
      
    
        
    选择这个对话要查阅的知识库。也可以直接在对话里说，比如“这个对话只用学习知识库”。
    
        
    
        
    
        
    
      
    
      
    
        
    把说明书、合同、笔记、电子书等文档加进来，聊天时 AI 会从中找相关段落回答，并注明出自哪份文档、第几页。文档只保存在这台手机上，按关键词检索，不消耗额度；下载一个模型后还能按意思检索。
    
        
        
        
    开启后，每次提问会先在知识库里找，找到相关段落就随问题一起发给模型；关闭后只在 AI 主动搜索时使用。
    
        
    
          
          
    换了说法也能找到相关段落，比如问“退租要提前多久说”，能找到“提前 30 日书面通知”。需要下载一个 334 MB 的模型，在手机上计算，文档不上传。
    
          
    
          
    
        
    
        
    
          分类知识库
          
    把文档分到不同的知识库，比如“工作”“学习”。每个对话可以选用其中几个：点输入框旁的“知识库”按钮，或在对话里直接说“这个对话只用学习知识库”。
    
          
    
          
    
        
    
        
    
        
    
          
          
          
    保存的是网页现在的内容，之后网页更新不会自动同步。
    
          
    
        
    
        
        
    
        
    
        
    
          
          
          
    
        
    
        
    
        
    
          同义词
          
    
          
          
          
    
        
    
        
    支持 PDF（扫描件用手机上的文字识别读取）、Word（.docx）、Excel（.xlsx）、EPUB、网页、Markdown 和文本文件。单个文件最大 100 MiB，最多 300 份。也可以在对话里说“把 xx.pdf 加入知识库”。
    
      
    
      
    
        
    点一下快捷任务，会把提示词填进输入框，或直接发送。最多 8 个，可调整顺序。
    
        
    
        
    
          
          
        
    
        
    
          添加快捷任务
          
          
          
          
    
          
          
    
        
    
        
    
      
    
      
    
        
        
    输入关键词搜索
    
        
    
      
    
      
    
        
        
    
        
    
      
    
      
    
        
        
    
        
        
    系统文件浏览器的「Agent Workspace」入口可浏览工作区和附件，按文件名搜索并读取。编辑请使用应用内文件页或公共文件夹。引擎停止后，请打开 Agent 启动引擎再重试。
    
        
    
        
    
          新建工作区
          
          
    
          
          
    推荐 Documents/AgentWorkspace 下的独立项目文件夹，便于用手机文件管理器查找、编辑和分享。此建议仅填写新建表单。
    
          
          
    
          
          
        
    
      
    
      
    
        
    工作区
    
        
    
        
    
          
    桌面小工具
    
          
    
          
    
        
    
        
    
        
    
          
    最近改动
    
          
    AI 或你改动、删除文件之前，会先存一份旧内容，保留 30 天。还原时，现在的内容也会先存一份。
    
          
    
          
    
        
    
        
    
          
    
            
            
    
              
              
              
              
            
    
            
            
            
            
            
          
    
          
    
          
          
    
        
    
      
    
      
    
        
        
        
    
        
    
          在电脑上继续
          
    把这段对话的文字和图片发到电脑，在电脑上新建一个对话接着做。
    
          
          
          
          
    
        
    
        
        
        
    归档只是从列表隐藏，可随时恢复；删除会彻底清除这段对话的聊天记录、任务和图片，无法恢复。在工作区里生成的文件不受影响。
    
      
    
      
    
        
        
    
        
      
    
      
    
        
    
        
    
        
    
        
    
        
      
    
      
    
        
        
        
        
        
    
        
        
    
      
    
      
    
        
        
    
        
        
    
          
    
          
    
        
    
        
    
          后台操作（实验）
          
          
    打开后，对话里的手机任务在一块看不见的后台屏幕上进行，你可以同时正常使用手机；从操作手机小窗发起的任务仍在前台。需要 Shizuku。同一个应用不能同时在前台和后台使用；后台应用发出的声音会从手机外放。
    
          
    
            安全说明
            
    开启后，对话里的手机任务会在一块你看不到的屏幕上进行。
    
            
    这需要 Shizuku 给本应用授予更高的系统权限。只在你自己的手机上开启，只给你信任的应用授权 Shizuku。
    
            
    后台的每一步仍按原来的规则执行：需要审批的操作照样先问你；付款、转账一律不做；你设为禁止的应用，AI 不会读取或操作。
    
            
    可以随时在这里查看后台屏幕、把应用移到前台，或关闭后台操作。
    
            
    不使用时，建议在 Shizuku 里停止服务，并关闭开发者选项中的无线调试。
    
            
    如果你没有开启过后台操作，却发现它是开着的，请立即关闭，并在 Shizuku 里撤销本应用的授权。
    
          
    
          
    
          
    
            设置步骤
            
      
          
      
          
      
          
        
      
        
        
      AI 操作手机时直接看当前画面：截图更快，画面在动（视频、动画）也能截到，Android 10 及以下也能截图。开启时系统会请你允许录制屏幕，状态栏会显示录屏标志；画面只留在手机上供 AI 截图用，半小时不用会自动关闭。
      
        
        
      
          不让 AI 操作的应用
          
      这些应用在前台时，AI 不会读取屏幕，也不会点按、输入或滑动（比如银行、支付类应用）。
      
          
      
          
          
      
            
            
      
          
      
        
      
        
      
          托管上限
          
      托管模式、定时任务和自动触发里操作手机时不会逐步问你，到达任一上限就停下，并告诉你做到了哪一步。付款、转账和支付密码在任何模式下都由你自己完成。
      
          
          
          
          
      
        
      
        
      
        
      
        
      
          内置浏览器
          
      AI 用它打开网页、点按钮、填表和截图。打开网页和点击需要你批准，只读取当前页面不用。它的登录状态与应用界面分开保存。
      
          
      
          
      
        
      
        
      
          闹钟与日历
          
      说“明早 7 点叫我”或“20 分钟后提醒我”，AI 会在系统时钟里设好闹钟或计时，不需要授权。查看和添加日程需要允许访问日历；在「工作区」执行模式下，添加日程前会先请你确认。
      
          
        
      
        
      
          联系人、位置与系统开关
          
      允许后，AI 可以按名字查联系人的电话、查看手机当前位置。短信只会在短信应用里替你写好，由你自己点发送。音量、亮度、勿扰和媒体播放可以让 AI 调整（需要你确认）；Wi‑Fi 和蓝牙只能由你在弹出的面板里开关。
