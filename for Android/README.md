# Agent Workspace Android 1.3

这是独立 Android APK 工程：Kotlin + WebView 界面、Chaquopy Python 3.12 运行时、私有 SQLite 事件库，以及 Android 原生无障碍动作桥。正常安装和使用 APK 不需要另装 Termux。旧 Termux 启动脚本是另一种开发宿主，不能据此推断 APK 已具有桌面程序或全部 Linux 工具。

模型、工作流、工具链、定时任务和设备诊断均在二级菜单。云模型凭据按服务来源存入 Android Keystore；可选模型文件和任务状态位于应用私有目录。升级应保留同一签名和 applicationId，并使用覆盖安装；卸载或清除应用数据会删除这些数据。

> 状态：1.3.0 正式版（更新内容见仓库根目录的 CHANGELOG.md）。升级请使用同一签名覆盖安装；卸载或清除应用数据会删除对话、设置和应用私有目录中的工作区。

## 功能概览

- **对话与任务**：本地或云端模型执行多步骤任务，流式显示回复、思考过程和每个工具调用的状态（执行中 / 已完成 / 失败 / 已取消）；需要授权的操作在输入区上方审批，可选「仅此次」「本会话」或「本任务内都允许」（任务结束即失效；删除文件、写入长期记忆和操作其他应用仍逐次询问）。
- **会话与工作区**：左上角会话列表按工作区切换会话，显示最近时间与运行中的任务；新会话会以第一条指令自动命名，不需要的会话可归档（记录保留，可恢复）。每个工作区对应一个文件夹，可新建、切换、移除（移除只取消登记，不删除文件）。
- **文件**：任务生成的文件可直接打开、预览、分享和另存；工作区文件页可浏览与编辑文本文件。
- **本地模型**：可下载 Qwen 系列 GGUF 在手机 CPU 上离线推理，含设备性能测试与内存估计。下载来源可选 ModelScope 魔搭（国内 CDN）或 Hugging Face，默认自动选择并可互相续传。工具调用由语法约束（GBNF）保证格式正确。
- **知识库**：把说明书、合同、笔记、电子书（PDF、Word、Excel、EPUB、网页、Markdown、文本）加进来，提问时自动找出相关段落并注明出处。按关键词检索（SQLite FTS5，中文按双字切分），内置常用同义词并可自定义，不需要下载模型，也不消耗额度。
- **闹钟与日历**：让 AI 在系统时钟里设闹钟和计时；允许访问日历后可查看和添加日程；在「工作区」执行模式下，添加前会先请你确认。
- **记忆**：AI 记住的关于你的信息，可查看、编辑和删除。
- **离线语音识别**：在「本地模型」下载 SenseVoice Small（int8，约 239 MB，FunASR 模型协议，Hugging Face 或 ModelScope）后，输入框的麦克风按钮在手机上识别中文、英文、日语、韩语和粤语，录音不上传、不保存；AI 可用 `transcribe_audio` 把工作区里的录音和视频转成带时间戳的文字，长录音分段接续。运行时为 sherpa-onnx 1.13.8（内含 ONNX Runtime，Apache-2.0 / MIT），仅随 arm64 打包（APK 约增加 8.6 MB），由 `prepare_speech_runtime.py` 固定版本和 SHA-256；x86_64 设备继续使用系统语音识别。
- **圈选提问**：长按悬浮球选「圈选提问」，在冻结的屏幕截图上圈出想问的部分（或整屏）发给 AI。未开启无障碍服务时，每次通过系统的截取屏幕授权（MediaProjection，只截一帧即停止）；开启后直接由无障碍服务截图，有密码框时拒绝截图。
- **桌面小组件**：「快捷提问」（4×1，像搜索框一样开新对话，也能直接语音或拍照提问）、「任务动态」（4×2，显示等待批准、正在执行或最近的任务，点开直达该对话）、「常用任务」（4×2，输入框上方的常用任务，点一下开新对话并填好指令）。可在 菜单 →「全局入口」一键添加，或长按桌面空白处从“小组件”里添加；组件跟随系统浅色 / 深色；应用选「液态玻璃」风格时组件也换成玻璃样式（半透明底板、亮边和顶部高光；桌面不允许小组件模糊背后的壁纸，所以没有真实的模糊和折射）。组件不做定时刷新，任务状态变化时由引擎服务更新。
- **自动化**：定时任务、可复用流程（含步骤回放）、任务评测、跨设备接力。
- **界面**：中文 / English（默认跟随系统），标准 / 液态玻璃两种风格（液态玻璃在 Android WebView 上有真实的边缘折射，见 `web_companion/static/liquid-glass.js`；可选五种预设背景、纯色或自定义壁纸），五种主题色，浅色 / 深色 / 跟随系统，动画可选完整 / 精简 / 关闭。新增界面文案写成 `t("中文原文")`，并在 `web_companion/static/i18n.js` 补充英文；缺少英文时测试会失败。

## 快速开始

1. 安装 APK（构建方法见下文「构建与贡献」），首次启动会初始化内置运行环境。
2. 在 菜单 →「服务商与 API 设置」填写云模型服务，或在 菜单 →「本地模型」下载一个本地模型。
3. 回到对话页输入任务；输入区下方的芯片可切换模型与思考强度，盾牌图标表示执行权限（绿色：仅工作区；黄色：YOLO；红色：完全访问）。

## 生成文件的交付

任务完成后，回复下方及任务中心显示实际生成或修改的文件链接。点击文件名可打开文件，旁边的图标提供系统分享和另存；历史重载后仍保留这些入口。Markdown、图片和静态 HTML 支持应用内预览，其他文档由已安装的应用打开。HTML 还提供隔离的交互预览，可执行文件内脚本，但不能联网或调用 Agent 原生桥。

下载使用认证接口和原始文件字节。可计算摘要的文件按完成时的 SHA256 校验，被删除或修改后会提示刷新，不能把旧链接当作新的文件版本。私有配置、凭据、运行数据库、上传输入及链接文件不会进入产物列表；扫描超出预算或中断后无法完整确认时会显示提示。分享与打开通过只读 `content://` 授权，另存使用 Android 系统文件选择器，不要求用户查找应用私有目录。

## 多文件导入与连续分享

聊天附件按钮和二级菜单“附件收件箱”使用 Android 系统文件选择器，支持一次多选。外部应用通过 `ACTION_SEND`、`ACTION_SEND_MULTIPLE` 或 `ClipData` 分享的文件先保存到持久收件箱；连续分享会追加文件，保留现有附件和输入草稿。用户可在收件箱统一选择目标会话、确认导入、重试或移除待处理文件。已经完成的导入不会因为后续文件失败而撤销。

原生接收和上传使用分块文件流，按实际存储空间判断是否可接收。每个文件保留稳定导入编号，重试核对会话、文件名、类型、大小和摘要；导入中断或应答丢失后，同一次请求不会生成重复文件。草稿保存成功后才确认并移除收件箱副本。普通浏览器入口也支持多选、进度、取消和重试，但尚未完成上传的浏览器文件选择不会跨页面重载保留。

该入口适配微信、QQ 等应用使用的标准 Android 文件分享协议；具体应用必须提供有效的 `content://` 文件和读取授权。接收尚未保存完成时授权被撤销，或设备存储不足，仍可能需要重新分享。系统协议测试不代表已经逐个实测所有微信、QQ 版本。

## PDF 与系统文件管理器

PDF 导入、原生读取、生成和导出均没有固定文件字节上限。读取和 OCR 按页执行，仍保留单次页数、文本返回量和渲染像素预算；大文档应按页分批处理。PDF 生成支持分页文本，读取支持文本提取、扫描页 OCR 和页图渲染，并非任意 PDF 排版编辑器。

系统文档选择器提供“Agent Workspace”工作区入口，可浏览、按文件名搜索和打开允许公开的文件。此入口为只读视图，需要应用引擎可用；不支持系统文档提供者的第三方文件管理器可能不显示它。用户也可指定可访问的公共文件夹作为工作区。应用配置、凭据和内部上传恢复记录不会出现在文件管理器中。

## 下载小模型并离线运行

本地引擎为固定版本 llama.cpp 的 JNI CPU 实现。权重是可选下载，APK 本身不带 GGUF 权重。模型菜单提供来源链接、体积、内存门槛、下载/取消/续传、完整性检查、选择/卸载和移除。只有完整文件通过固定 SHA256 后才会显示为可用；选中本地模型时不应自动退回云模型。

**Qwen3.5 0.8B Q4_K_M** 适合短问答、摘要和少量明确的工具动作；日常多步骤任务优先评估 **2B Q4_K_M**，以真机速度和任务成功率决定是否适用。当前八个固定条目如下，完整 revision、文件名、字节数和摘要见 `mobile_model_catalog.py`。大小为十进制 MB/GB；可用 RAM 是 4096 token CPU 上下文的保守加载门槛，还需为 Android 和应用预留内存。

| 模型 | 量化 | 下载大小 | 估计可用 RAM | GGUF 发布者 |
|---|---|---:|---:|---|
| Qwen3.5 0.8B | Q4_K_M | 532.5 MB | 1024 MiB | Unsloth 社区量化 |
| Qwen3.5 0.8B | Q8_0 | 811.8 MB | 1280 MiB | Unsloth 社区量化 |
| Qwen3.5 2B | Q4_K_M | 1.281 GB | 1728 MiB | Unsloth 社区量化 |
| Qwen3.5 2B | Q8_0 | 2.012 GB | 2432 MiB | Unsloth 社区量化 |
| Qwen3 0.6B | Q4_K_M | 396.7 MB | 1280 MiB | Unsloth 社区量化 |
| Qwen3 0.6B | Q8_0 | 639.4 MB | 1536 MiB | Qwen 官方 GGUF |
| Qwen3 1.7B | Q4_K_M | 1.107 GB | 1984 MiB | Unsloth 社区量化 |
| Qwen3 1.7B | Q8_0 | 1.834 GB | 2800 MiB | Qwen 官方 GGUF |

Qwen3.5 的门槛依据固定 GGUF SHA256、官方固定版本 config 和本 APK 的 llama.cpp 分配方式：24 层中只有 6 层使用完整注意力；4096 token 的 F16 KV 为 48 MiB，18 层 F32 循环状态实际约 19.3 MiB，保守预留 64 MiB，另保留 384 MiB 计算空间。冷加载完整计入新模型权重并向上取整到 64 MiB；相同模型已加载时仍保留新上下文空间。只有安装摘要和文件大小匹配固定条目才使用该估计，其他文件保留原来较高的缓存预留；Android `lowMemory` 与 4096 token 上限仍然生效。公式和来源见 [内存估计证据](docs/qwen35-memory-estimate-evidence.json)。

Qwen3.5 的基础模型来自 Qwen；目录中的 Qwen3.5 GGUF 和配套视觉组件由 Unsloth 发布，不能标注为 Qwen 官方 GGUF。本地文本、工具和图片推理均使用 CPU。手机温度、内存压力、线程数和上下文长度都会影响速度；目录能力与单元测试不能证明某个手机上的推理性能。首次 token、吞吐和实际生成应以设备测量为准。

## 本地与云端图片输入

聊天附件支持 PNG、JPEG、WebP 和 GIF 图片，每次最多 4 张，每个文件最多 4 MiB。本地 GIF 读取首帧；HEIC、HEIF 和 AVIF 需先转换为上述格式。图片以真实字节输入模型，普通文档继续作为工作区文件交给工具读取。可只发图片，也可附带问题。

本地 Qwen3.5 需同时下载对应的视觉组件：0.8B 的 F16 组件约 205 MB，2B 约 668 MB。二级菜单“本地模型”提供下载来源、校验、暂停、续传和移除；视觉组件与文本权重共享下载队列，不能作为独立聊天模型选择。Qwen3 文本条目不支持图片。组件不匹配、缺失、图片损坏或内存不足都会返回明确错误。本地模式保持本地执行。

图片会先按当前会话的导入记录和 SHA256 校验，再与任务原子保存到私有事件库。排队、原附件删除或引擎重启不会改变已提交任务的图片内容；恢复沿用已保存的图片历史。旧草稿在发送前补查附件元数据，校验失败时保留草稿并显示原因。

云端复用桌面端的 OpenAI Chat Completions、OpenAI Responses、Anthropic、Gemini 和 Ollama 图片协议。需要选择实际支持视觉的模型和服务端；服务端不支持图片时显示其错误。协议编码测试和某一个云模型的实测不能证明所有第三方服务或所有模型均兼容。

本地图片先有界解码为最长边 512 像素的 RGB，再由 llama.cpp mtmd 计算真实视觉 token。4096 token 总上下文上限、取消和低内存保护继续生效；加载估计在文本所需内存之外，完整计入视觉组件文件大小与 256 MiB 额外计算空间。因此能运行 2B 文本不代表同样的可用内存能运行 2B 图片。固定组件来源、摘要、参数和内存公式见 [视觉适配证据](docs/qwen35-vision-evidence.json)。

本地单次推理的 4 张图片限制包含当前上下文中的历史图片和工具截图。超过限制时需新建会话；应用会明确报错。云端图片上限和视觉能力由所选服务决定。

本机模式按需公布工具：先提供少量核心工具，模型可通过只读 `select_local_tools` 请求其他已注册工具，下一轮才加入其完整参数。工具执行仍走原有权限、参数校验和结果记录。微调前应先收集实际任务中的错误类型；LoRA 可以改善本应用的工具格式和选择习惯，小模型的多步推理、长上下文和视觉能力仍需独立验证。

## 工作流、审批和恢复

旧保存目标仍可运行。版本 2 工作流保存声明式动作，使用资源 ID、文本等语义选择器，每步重新观察当前树并选择新引用，检查前置和后置状态。支持选择控件点击、普通文本输入、启动应用、返回和主页；每步最多 5 秒，最多两次额外重试，仅对 Android 明确报告“未执行”的过期快照重选。

运行记录在动作派发前写入检查点。已执行动作不会重放；失去执行结果的动作标记为 unknown，停止并禁止自动继续。安全检查点的恢复必须明确确认，重新检查最后确认的屏幕状态，并沿用当前会话审批与取消策略。保存工作流不会授予无限制权限。录制入口导入用户审阅过的、确认执行的动作，丢弃受保护文本和未确认动作，不会被动保存私人 UI。JSON 导入/导出最大 256 KiB。示例和恢复语义见 [WORKFLOWS_AND_EVALUATIONS.md](WORKFLOWS_AND_EVALUATIONS.md)。

无障碍服务需要在 Android 设置中由用户开启。密码/敏感控件、隐藏或不明确的目标、变化中的树会被拒绝。安全锁屏需要用户正常解锁；应用不能绕过 keyguard。

## 可选开发工具链与后台限制

设备菜单可下载固定 Alpine 3.22.6 工具链，约 69 MB 下载，安装需预留至少 700 MiB。APK 包含经过摘要验证的 Android PRoot 启动器，作为独立进程执行；工具包和根文件系统是可选下载。支持的 ABI 为 arm64-v8a 和 x86_64。安装完成后实际执行 shell、Git、Python、Node 和 Pyright 探测，全部通过后才广告可用工具。失败或不支持的架构有明确原因，不能将桌面 exe 或仅存在的文件当作可用程序。详见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

前台服务、持久化任务/定时状态和 WorkManager 恢复减少中断，但不能保证 OEM 冻结、Doze、低内存终止或重启后的准点运行。诊断页面显示电池优化/服务状态和恢复入口；用户停止状态会保留，错过的调度需要按记录核对，不能重复执行不明动作。真实设备覆盖和限制必须随测量报告披露。
