# Android 交互层设计：终端 CLI 与移动 Web 控制台

> 文档编号：AW-AND-05  
> 核心原则：用低成本、高质感的现代 Web 与终端交互，彻底替代笨重不可移植的 PySide6 桌面。

---

## 1. 为什么“移动 Web 伴侣”是体验最佳解？

在手机上，用户最舒服的输入体验来自**手机系统自带的虚拟输入法**（搜狗、微信键盘、Gboard），最舒适的阅读体验来自**移动浏览器内核对字体的渲染与平滑触摸滑动**。

因此，本项目在 Android 上的第一推荐形态为：
> **Termux 后台守护运行 Agent 引擎 + 手机浏览器（Chrome/Firefox/Edge）打开本地 `http://127.0.0.1:8080` 控制台。**

配合 PWA（Progressive Web App）技术，用户只需在 Chrome 菜单点击 **“添加到主屏幕”**，即可生成一个没有地址栏、带独立桌面图标、沉浸式全屏的“原生级 App”！

### 2.2 核心体验特性实现清单

1. **虚拟键盘自适应避让 (Visual Viewport API)**：
   * 手机输入法弹起时，传统网页会被顶飞或内容错位。
   * 引入 `window.visualViewport` 动态监听软键盘高度，输入框自动贴合键盘顶部，会话列表平滑滚动对齐。
2. **移动端代码 Diff 查看器**：
   * 手机屏幕宽度有限，放弃双栏 Diff（Side-by-Side），强制采用**单栏行内混合 Diff（Inline Diff）**；
   * 字体强制设为移动端优化的等宽字体：`ui-monospace, 'Cascadia Code', 'JetBrains Mono', monospace`，字号 13px，支持横向溢出平滑拖动。
3. **PWA 桌面图标与全屏配置 (`manifest.json`)**：
   ```json
   {
     "name": "Agent Workspace",
     "short_name": "Agent",
     "start_url": "/console",
     "display": "standalone",
     "background_color": "#0d1117",
     "theme_color": "#161b22",
     "icons": [
       { "src": "/icon.png", "sizes": "192x192", "type": "image/png" }
     ]
   }
   ```
4. **SSE 实时流式与触摸滚动互不干扰**：
   * 增加“触底锚定（Pin to Bottom）”算法：如果用户正在向上滑动回看历史代码，即使模型正在高速吐字打字，页面也**不会强行打断用户的浏览跳回底部**；仅当滚动条处于最底端时才自动跟进。

## 3. 终端形态优化：手机狭窄屏幕下的 CLI (TUI)

在通过 Termux 纯终端直接操作时，手机竖屏通常只有 40~60 字符宽度（相比电脑的 120+ 宽度极其狭窄）。

### 3.1 终端适配改造点
1. **自动列宽探测与折行**：
   ```python
   import shutil


   def get_adaptive_console_width() -> int:
       cols, _ = shutil.get_terminal_size((80, 24))
       return max(36, cols)  # 即使在竖屏超窄情况下也保持格式不崩坏
   ```
2. **紧凑模式（Compact Output）**：
   * 废除宽表格（Table）渲染，在窄屏终端自动转换为轻量垂直列表（Key-Value List）；
   * 隐藏不必要的 ASCII 大横幅（Banner），启动直接进入输入提示符。
3. **输入法友好与快捷键指引**：
   * Termux 底部自带虚拟功能键栏（Extra Keys）。CLI 启动时在底部提示：
     `[Ctrl+C 取消] [Ctrl+D 退出] [Enter 发送]`，方便单手触摸操作。
